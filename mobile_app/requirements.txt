# ------------------------------------------------------------------------------
# 2. KEY FEATURES & REQUIREMENTS SPECIFICATION
# ------------------------------------------------------------------------------

Feature 1: Individual OpenRouter / OpenAI Key Configuration
- Screen: lib/views/settings_view.dart
- Details: Users paste their personal OpenRouter Key (sk-or-v1-...) or OpenAI Key.
- Storage: Saved locally in encrypted device preferences (shared_preferences).
- Header: Attached automatically to AI completion requests via `Authorization: Bearer <key>`.

Feature 2: Active Live Session Guard & Single Session Lock
- Screen: lib/views/mock_interview_view.dart
- Details: Prevents duplicate interview creation if a live session is active.
- Warning: Displays alert `⚠️ You already have an active live interview session. Please complete or end that session first.`
- Controls: Includes prominent "End Session" action button in AppBar to complete interview and generate report.

Feature 3: Network Connection & Offline Detector
- Widget: lib/widgets/custom_widgets.dart (NetworkOfflineBanner)
- Details: Detects offline network status using `connectivity_plus`.
- Alert: Displays banner `⚠️ Offline Mode: No Internet Connection. Reconnecting...`

Feature 4: 100% Genuine Actual Performance Evaluation
- Details: Evaluation reports calculate scores strictly from recorded candidate speech & Q&A.
- Low Score Guard: 0 candidate answers return an accurate low score/needs improvement rating rather than false defaults.

Feature 5: Live Video Preview & AI Audio Visualizer
- Details: Displays live camera stream box (REC LIVE indicator) alongside AI interviewer avatar (Sophia AI).
